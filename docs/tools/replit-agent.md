## Replit Agent 是什么？

<div class="tool-prose-card">
  <p>Replit 官方把 Agent 定义为“把你的想法变成应用、设计、演示和更多内容的智能体”，而不是单纯的代码补全器。它的定位非常明确：用户直接用自然语言描述目标，Agent 负责创建项目、写代码、搭基础设施、测试结果并继续迭代。</p>
  <p>和传统 IDE 助手相比，Replit Agent 更接近“从需求到成品”的全流程构建工具，尤其适合不想先从本地环境、仓库初始化和部署流程开始的人。它对非纯工程背景用户尤其友好，所以在 AI coding agent 里属于非常有代表性的产品。</p>
</div>

## 主要功能

<div class="tool-feature-grid">
  <article class="tool-feature-card">
    <h3>自然语言生成完整项目</h3>
    <p>官方文档强调它可以从 plain language 出发，构建应用、设计、演示、数据可视化等多种产物，不要求先会写代码。</p>
  </article>
  <article class="tool-feature-card">
    <h3>Plan Mode 与多种 Agent 模式</h3>
    <p>Replit Agent 不只有一个“开始干活”按钮，还提供 Plan Mode、Lite / Economy / Power / Turbo 等不同层级的工作模式。</p>
  </article>
  <article class="tool-feature-card">
    <h3>云端工作区与部署一体化</h3>
    <p>它不是只返回代码片段，而是直接在 Replit 的云端工作区里创建项目、运行、调试和发布，更像一个完整开发平台里的 Agent。</p>
  </article>
  <article class="tool-feature-card">
    <h3>连接器与任务板</h3>
    <p>官方资料显示它支持连接第三方服务、任务规划和看板式推进，说明它已经不只是对话式工具，而是在往项目型 agent 演进。</p>
  </article>
</div>

## 如何使用？

<div class="tool-step-list">
  <article class="tool-step-card">
    <span class="tool-step-no">01</span>
    <h3>描述想构建什么</h3>
    <p>进入 Replit 后，直接描述你想做的应用、页面、演示或数据可视化结果，Agent 会判断合适的构建方向。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">02</span>
    <h3>选择模式</h3>
    <p>简单修改可用轻量模式，复杂构建则进入更强的 Full Build、Plan Mode 或高级 Agent 模式。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">03</span>
    <h3>审查计划和中间结果</h3>
    <p>查看它生成的计划、Checkpoint 和构建结果，必要时继续让它修复、重构或追加功能。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">04</span>
    <h3>发布并继续迭代</h3>
    <p>项目完成后可以直接发布、继续聊天迭代，或者使用可视化编辑与更多连接器扩展工作流。</p>
  </article>
</div>

## 价格与套餐

<div class="tool-prose-card">
  <p>截至 <strong>2026 年 5 月 28 日</strong>，Replit 官方价格页和官方 Billing 文档可以明确确认：<code>Starter</code> 免费，<code>Core</code> 为 <strong>20 美元/月（年付口径）</strong>，<code>Pro</code> 为 <strong>95 美元/月（年付口径）</strong>。同时 Agent 使用遵循 credits 和按量计费逻辑，超出套餐 credits 后按使用量继续结算。</p>
  <p>官方还特别强调 Agent 的计费已经从早期固定 checkpoint，转向 <code>effort-based pricing</code>，也就是按任务实际工作量计费。因此站内既要写订阅档位，也要提醒用户：复杂请求可能明显更贵。</p>
</div>

## 补充说明

<div class="tool-note-list">
  <article class="tool-note-card">
    <h3>它比纯代码 Agent 更产品化</h3>
    <p>Replit Agent 不是给工程师的一个局部插件，而是一个从想法到应用的完整构建环境，更适合放在“AI Builder / 应用生成 Agent”类目里。</p>
  </article>
  <article class="tool-note-card">
    <h3>按工作量计费要写清楚</h3>
    <p>用户最容易误解的是“订阅后是不是无限用”。官方已经明确不是，需要同时理解套餐 credits 和 effort-based pricing。</p>
  </article>
  <article class="tool-note-card">
    <h3>和传统 no-code 平台也不完全一样</h3>
    <p>它虽然降低了门槛，但底层仍是更完整的开发工作区，所以它的扩展能力和复杂度都比普通表单式 no-code 更高。</p>
  </article>
</div>
