## 公开入口

<div class="tool-feature-grid">
  <article class="tool-feature-card">
    <h3>OpenRouter</h3>
    <p>最知名的统一模型入口之一，支持大量模型和 OpenAI 兼容调用方式，适合做多模型切换和快速验证。</p>
    <p><a href="https://openrouter.ai/" target="_blank" rel="noreferrer">官网</a> · <a href="https://openrouter.ai/docs/quickstart" target="_blank" rel="noreferrer">文档</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>QuickRouter</h3>
    <p>主打快速切换多个主流模型供应商的聚合式 API 入口，公开页面展示兼容调用方式和接入示例。</p>
    <p><a href="https://quickrouter.ai/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>Sublyx</h3>
    <p>统一 AI API 网关，公开说明了 OpenAI / Claude / Gemini 聚合、统一 key、路由和控制台能力。</p>
    <p><a href="https://sublyx.org/en/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>CCRelay</h3>
    <p>更偏本地网关和开发工具链兼容，公开说明支持 Claude Code、Cowork 和 Codex 等工作流。</p>
    <p><a href="https://ccrelay.inflab.org/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>CCAPI</h3>
    <p>统一多模态 AI API 网关，公开介绍支持多家模型供应商并提供 OpenAI 兼容接入方式。</p>
    <p><a href="https://www.ccapi.ai/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>OkRouter</h3>
    <p>主打企业级统一 AI Gateway，公开提供模型页和接入文档，适合偏生产化使用的场景。</p>
    <p><a href="https://okrouter.ai/" target="_blank" rel="noreferrer">官网</a> · <a href="https://okrouter.ai/docs/api-keys" target="_blank" rel="noreferrer">文档</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>api-hub.ai</h3>
    <p>以统一请求格式、切换模型和用量分析为卖点的 AI API 聚合入口，适合需要控制台分析能力的用户。</p>
    <p><a href="https://www.api-hub.ai/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">
    <h3>Celedog</h3>
    <p>公开定位为单一 OpenAI 兼容入口背后的多模型网关，页面展示了较多模型支持信息。</p>
    <p><a href="https://celedog.io/" target="_blank" rel="noreferrer">官网</a></p>
  </article>
  <article class="tool-feature-card">

  </article>

    <p><a href="https://www.aihubproxy.com/" target="_blank" rel="noreferrer">官网</a></p>
