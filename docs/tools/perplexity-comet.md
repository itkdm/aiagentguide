## Perplexity Comet 是什么？

<div class="tool-prose-card">
  <p>Perplexity 官方将 Comet 定义为一款由 AI 驱动的浏览器。根据官方帮助中心，Comet 是基于 Chromium 的浏览器，把传统浏览器能力和 Perplexity 的搜索、理解、摘要、记忆与助手能力结合到了一起。</p>
  <p>它和普通浏览器最大的区别，不在“能不能打开网页”，而在于它试图把浏览器从“页面容器”变成“任务工作台”。你可以在浏览网页时直接提问、压缩长内容、调用 Gmail 连接器、利用浏览历史做个人搜索，甚至让浏览器更主动地协助你完成任务。</p>
</div>

## 主要功能

<div class="tool-feature-grid">
  <article class="tool-feature-card">
    <h3>AI 搜索默认内嵌</h3>
    <p>官方帮助中心明确写到，Perplexity AI 驱动的搜索是 Comet 的主要搜索引擎，用来获取更准确、可验证的信息。</p>
  </article>
  <article class="tool-feature-card">
    <h3>Comet Assistant</h3>
    <p>Comet Assistant 可以结合你当前打开的网页和浏览上下文回答问题，不需要频繁在浏览器和聊天窗口之间切换。</p>
  </article>
  <article class="tool-feature-card">
    <h3>个人搜索与记忆</h3>
    <p>官方说明 Comet 会使用与你的 Perplexity 账户一致的 memory 系统，让浏览器更好地理解你的搜索历史与偏好。</p>
  </article>
  <article class="tool-feature-card">
    <h3>面向工作流的浏览器能力</h3>
    <p>官方页面和帮助中心都强调摘要、网页问答、Gmail 连接器、广告拦截和更偏任务型的浏览体验。</p>
  </article>
</div>

## 如何使用？

<div class="tool-step-list">
  <article class="tool-step-card">
    <span class="tool-step-no">01</span>
    <h3>下载并安装 Comet</h3>
    <p>根据官方站点，Comet 目前支持 Mac、Windows、iOS 和 Android，可直接下载安装。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">02</span>
    <h3>导入浏览器数据</h3>
    <p>官方帮助中心提供了从其他浏览器导入书签、设置和历史数据的标准流程，方便无缝迁移。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">03</span>
    <h3>用 Assistant 处理网页任务</h3>
    <p>打开网页后，可以用 Assistant 询问当前页面、提炼长文、结合搜索做信息对比，或者进入更任务型的使用方式。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">04</span>
    <h3>根据需要开启 memory 和连接器</h3>
    <p>如果你希望得到更个性化结果，可以在 Perplexity 账户层面开启记忆选项，并按需使用 Gmail 等连接器。</p>
  </article>
</div>

## 价格与套餐

<div class="tool-prose-card">
  <p>截至 <strong>2026 年 5 月 28 日</strong>，Comet 作为浏览器本身的个人版独立定价并没有在官方公开页面形成一张非常清晰的单独价格表。站内如果写“个人版多少钱”，容易和 Perplexity 其他产品线混淆。</p>
  <p>但官方企业帮助页可以明确确认企业座席价：<code>Enterprise Pro</code> 为 <strong>40 美元/席位/月</strong> 或 <strong>400 美元/席位/年</strong>，<code>Enterprise Max</code> 为 <strong>325 美元/席位/月</strong> 或 <strong>3250 美元/席位/年</strong>。因此更稳妥的写法是：个人侧单独价格口径不清晰，企业侧可按 seat 理解。</p>

## 补充说明

<div class="tool-note-list">
  <article class="tool-note-card">
    <h3>它比普通浏览器更像工作台</h3>
    <p>Comet 不只是把搜索换成 Perplexity，而是把搜索、记忆、连接器和助手面板揉成一个更连续的浏览流程。</p>
  </article>
  <article class="tool-note-card">
    <h3>Memory 复用的是 Perplexity 账户体系</h3>
    <p>官方帮助页明确说明，Comet 本身不单独存储一套独立记忆，而是使用 Perplexity 账户下的 memory 体系。</p>
  </article>
  <article class="tool-note-card">
    <h3>很适合放在“AI 浏览器 / 浏览器 Agent”分组</h3>
    <p>如果你后面要继续扩工具目录，Comet 应该和 Browser Use、Claude Cowork 这类“操作层/浏览层 Agent”形成一个子类目。</p>
  </article>
</div>
