## Claude Cowork 是什么？

<div class="tool-prose-card">
  <p>Claude Cowork 是 Anthropic 在 Claude Desktop 里提供的一种“让 Claude 直接操作你的电脑”的能力。官方帮助中心在 <strong>2026 年 4 月 24 日</strong> 的说明里明确写到：当 Claude 没有现成 connector 或工具时，它可以直接导航你的屏幕，像人一样点击、输入、打开应用、使用浏览器和运行开发工具。</p>
  <p>如果你把它和普通聊天式 AI 工具相比，区别在于 Claude Cowork 不只是“告诉你该怎么做”，而是可以在你授权后真正去操作界面。它更接近一个带有人在环审批和应用级权限控制的桌面 agent，适合处理浏览器任务、文件整理、应用间切换以及部分研发、研究和办公流程。</p>
</div>

## 主要功能

<div class="tool-feature-grid">
  <article class="tool-feature-card">
    <h3>直接操作桌面与应用</h3>
    <p>Claude 可以通过截图理解当前界面，并在获批后进行点击、输入、切换窗口和打开应用等操作，而不只是返回一段建议文字。</p>
  </article>
  <article class="tool-feature-card">
    <h3>连接器优先，再退到屏幕交互</h3>
    <p>官方说明 Cowork 会优先使用 Gmail、Google Drive、Slack 等连接器；如果没有连接器，再通过浏览器导航或直接屏幕交互完成任务。</p>
  </article>
  <article class="tool-feature-card">
    <h3>浏览器与本地文件协同</h3>
    <p>它可以在浏览器里查资料、打开本地文件、结合连接器和桌面应用整理结果，适合跨工具、多步骤的知识工作流。</p>
  </article>
  <article class="tool-feature-card">
    <h3>权限确认与安全边界</h3>
    <p>Claude 会在访问每个应用前请求权限，某些敏感应用默认受限；而且你可以随时停止它，并通过 blocklist 阻止特定应用被访问。</p>
  </article>
</div>

## 如何使用？

<div class="tool-step-list">
  <article class="tool-step-card">
    <span class="tool-step-no">01</span>
    <h3>在 Claude Desktop 中启用能力</h3>
    <p>根据 Anthropic 官方说明，Cowork 与 Claude Code 的电脑操作能力都在 Claude Desktop 中提供，支持 macOS 和 Windows。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">02</span>
    <h3>先给出清晰、具体的任务</h3>
    <p>例如整理一份研究材料、跨多个来源更新表格、打开模拟器检查应用体验，或借助浏览器与本地文件完成一份报告。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">03</span>
    <h3>按应用逐步授权</h3>
    <p>当 Claude 需要访问 Finder、Chrome、剪贴板或其他桌面应用时，会弹出权限请求。你可以按应用决定是否放行，而不是一次性全盘开放。</p>
  </article>
  <article class="tool-step-card">
    <span class="tool-step-no">04</span>
    <h3>全程观察并在关键步骤接管</h3>
    <p>它适合做研究、整理、查找、录入等任务，但涉及敏感信息、财务、合同、医疗或高风险决策时，应该由人主动接管和复核。</p>
  </article>
</div>

## 价格与套餐

<div class="tool-prose-card">
  <p>截至 <strong>2026 年 5 月 28 日</strong>，Anthropic 官方帮助中心明确写到：<strong>computer use is in research preview for Pro and Max plans</strong>。也就是说，Claude Cowork 的这项电脑操作能力当前并不是对所有 Claude 用户统一开放，而是处于研究预览状态，并面向 <code>Pro</code> 与 <code>Max</code> 计划。</p>

## 补充说明

<div class="tool-note-list">
  <article class="tool-note-card">
    <h3>它不是沙盒浏览器</h3>
    <p>Anthropic 官方明确提醒，Cowork 的电脑操作在你的应用和桌面上直接执行，并不存在一个完全隔离的本地沙盒。这意味着它更强，也意味着需要更谨慎。</p>
  </article>
  <article class="tool-note-card">
    <h3>敏感场景不适合默认放手</h3>
    <p>官方建议避免把它直接用于银行、医疗、政府、投资等敏感应用，也不应把它当作处理密码、合同、财务或他人隐私数据的默认自动化工具。</p>
  </article>
  <article class="tool-note-card">
    <h3>和 API 里的 computer use 不是一回事</h3>
    <p>Anthropic 同时提供面向开发者的 computer use API 工具，以及面向终端用户的 Claude Cowork 电脑操作能力。你网站里如果后面要扩内容，建议把“终端产品能力”和“API 能力”分成两页讲。</p>
  </article>
</div>
