# 基础用法

基础用法解决的是“怎么开始正确使用 Coding Agent”。在让 Agent 修改代码之前，先要知道它适合做什么、任务怎么描述、项目规则怎么交代。

你会在这里看到：

- Coding Agent 适合做什么，不适合做什么
- Codex、Claude Code 等工具的基础使用边界
- 如何描述一个清晰的开发任务
- 如何写项目级指令文件，例如 `AGENTS.md`、`CLAUDE.md`
- 如何让 Agent 先阅读项目，再开始修改
- 新手使用 AI 编程助手时常见的误区

这一部分的重点不是工具功能清单，而是建立基本判断：什么时候可以让 Agent 动手，什么时候应该先让它分析、规划或复述约束。
