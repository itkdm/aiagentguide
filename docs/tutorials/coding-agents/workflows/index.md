# 开发工作流

开发工作流关注 Coding Agent 如何参与真实项目，而不是只完成一次孤立的代码生成。重点是把需求、项目上下文、任务拆解和代码提交连成稳定流程。

你会在这里看到：

- 如何让 Coding Agent 接手一个陌生项目
- 如何把需求拆成可以执行的任务
- 如何管理长上下文、压缩信息和恢复任务
- 如何设计分支、提交和推送流程
- 如何从需求讨论进入实现计划
- 大型代码库中如何分阶段推进
- 如何处理长任务、中断和继续执行

这一部分的重点是可复用流程。不同工具的命令和界面会变，但“先理解项目、再拆任务、再小步验证”的顺序不应该变。
