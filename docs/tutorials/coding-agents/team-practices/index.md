# 团队实践

团队实践关注的是个人之外的问题：当 Coding Agent 进入一个团队，它需要接入已有工程流程，而不是变成每个人各用各的临时工具。

你会在这里看到：

- 团队如何约定 Coding Agent 的工作边界
- 如何设计分支、提交和 Pull Request 流程
- 如何写团队级仓库指令和协作规范
- 如何让 Agent 参与代码评审、issue 处理和文档维护
- 如何处理权限、审批、安全和合规边界
- 如何拆解 OpenAI、Ramp、Cisco 等公开团队实践
- 如何把 Slack、GitHub、CI 或内部平台接入 Agent 工作流

这一部分会提到具体工具，但重点放在团队流程和工程治理上，而不是工具功能介绍。
