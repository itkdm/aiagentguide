# Coding Agent 实战方法

Coding Agent 不只是“让模型写代码”。在真实项目里，更重要的是让它先理解项目、拆清任务、控制修改范围，并用测试或代码审查验证结果。

这个专题按开发场景整理 Codex、Claude Code 等工具的实践方法。你可以把它当作一组工作流参考，而不是工具功能说明。

## 从哪里开始

- 如果刚开始使用 Coding Agent，先看 [基础用法](./basics/)。
- 如果想把它用于真实项目开发，重点看 [开发工作流](./workflows/)。
- 如果担心 Agent 乱改、漏测或过早声明完成，看 [质量控制](./quality/)。
- 如果关注团队如何使用 Codex、Claude Code 或类似工具，看 [团队实践](./team-practices/)。
- 如果想看具体项目和外部经验拆解，看 [实战案例](./cases/)。

## 阅读重点

读这个专题时，不要只看工具命令。更值得关注的是任务如何描述、上下文如何给、修改范围如何控制、完成前如何验证。
