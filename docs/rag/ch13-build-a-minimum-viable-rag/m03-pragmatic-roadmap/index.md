# 13.3 一个务实的落地顺序

先给结论：*务实的顺序不是“从最先进开始”，而是“从能稳定跑通开始”。把最少的资源用在最大可控的环节上，才能走得远。*

这一节从“资源有限”和“阶段演进”的角度，给出一个可执行的 RAG 建设顺序。评估与观测是长期稳定迭代的关键能力，也必须被纳入路线图中。
