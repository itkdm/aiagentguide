# 项目实践

在这个栏目，我们会围绕 Agent 生态来做一些真正的项目实践。

内容不只包括 Agent 本身，也会涉及 RAG、计费、观测、评测、权限、前后端协作等等。

项目不会为了讲清某个知识点临时搭建一个 Demo，而是会尽量建立在真实开源项目、真实需求或接近生产环境的工程约束之上。

有些项目可能从一个已有开源项目继续扩展，有些可能围绕一个真实功能逐步实现，也可能会直接以 Issue、PR 或实际开发需求作为起点。

我希望一个项目既能承担教程的作用，又不只是为了教程而存在。

同时尽量让这些项目开源，兼顾教程学习和企业实际使用的需要，让项目既能帮助大家理解技术，也具备继续落地和使用的价值。

实现过程中我们不会只关注“功能能不能跑起来”，还会继续讨论为什么这样设计、怎样接入已有系统、哪些边界需要提前考虑，以及异常处理、测试、可靠性、可维护性和后续扩展等问题。

项目不会限定在某一种语言或框架。现阶段我们会先从大多数同学比较熟悉的工程体系开始，语言上更倾向于 Java，前端则以 Vue、React 为主。

[若依](https://github.com/yangzongzhuan/RuoYi-Vue)、[芋道](https://github.com/YunaiV/ruoyi-vue-pro)等二次开发框架在不少中小型企业项目中都有实际应用，后续我们也会基于这类成熟工程体系，重点开发 Agent 相关模块。随着项目增加，再逐步加入 Python、TypeScript、Go 等技术栈。

语言只是实现方式，更重要的是理解 Agent 相关能力如何一步步进入一个可以长期维护和继续发展的系统。

另外，后续如果遇到值得做的想法、真实企业需求或者有意思的开源方向，我同样会发起一个新的项目带领大家来一起实现。

项目会持续增加，已经开始的项目也会不断完善。

希望能给大家在学习、面试、工作中带来一些帮助！
